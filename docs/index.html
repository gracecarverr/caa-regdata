Stationary-source pollution, turned into research infrastructure.

A reproducible pipeline of U.S. Environmental Protection Agency (EPA) enforcement, compliance, and permitting data on stationary sources of air pollution under the Clean Air Act — built for empirical research on regulation and compliance.

How the pipeline works

Four stages, run in order by code/RUN_ALL.R, each reading only the previous stage's output.

01

Download

Pull raw sources from EPA ECHO into data/raw/*.

02

Clean

Raw sources → bare-bones clean assets in data/processed/*.csv.gz.

03

Datasets

Build the eight deliverable datasets in data/datasets/*.csv.gz.

04

Panels

Build two facility × year panels in data/panels/*.csv.gz.

Public EPA sources

Downloaded at run time by code/01_data_download/01_download.R. None are redistributed here.

Core CAA Sources

ICIS-Air

Facility identification, compliance monitoring, and enforcement data for stationary air sources — the pipeline's primary source.

Air Emissions

Facility-level pollutant emissions, combining NEI, GHGRP, TRI, and CAMD.

CAA Compliance Pipeline

Violations pre-joined to their triggering evaluation and resulting enforcement action.

AFS (Air Facility System, pre-2014)

Legacy facility, program, action, and HPV-history tables, frozen as of 2014 — ICIS-Air's predecessor.

Crosswalk

FRS (Facility Registry Service)

Cross-program facility registry — the source of this pipeline's facility coordinates.

US Counties (Census TIGER)

County boundaries, used for the point-in-polygon coordinate-to-county match.

Automatically generated from the underlying data — no figures are hand-entered. Part of the caa-regdata reproducible pipeline.
